# Vid2Tweet Design System

Minimal Airtable-inspired design tokens for the Vid2Tweet frontend.

## Palette
- `--color-bg`: #F8F7F3
- `--color-surface`: #FFFFFF
- `--color-text`: #1F2937
- `--color-muted`: #6B7280
- `--color-primary`: #2D7FF9
- `--color-primary-hover`: #1D6AE5
- `--color-accent`: #F59E0B
- `--color-success`: #10B981
- `--color-error`: #EF4444

## Typography
- Font stack: Inter, system-ui, sans-serif
- Headings: 600-700 weight
- Body: 400-500 weight

## Spacing
- Base unit: 4px
- Common scale: 4, 8, 12, 16, 24, 32, 48

## Shape
- Radius sm: 6px
- Radius md: 10px
- Radius lg: 16px

## Components
- Cards: white surface, subtle border, soft shadow
- Buttons: rounded, blue primary, clear hover state
- Inputs: light border, focused blue ring

## Visual Tone
- Clean, friendly, data-first
- High contrast for readability
- Lightweight product UI, not decorative
